# REST API

Базовый путь `/api`. JSON UTF-8. Защищённые маршруты требуют `Authorization: Bearer <token>`. Даты — `YYYY-MM-DD`, идентификаторы — положительные целые числа. Ошибка: `{"error":"Описание"}`, в случае валидации может присутствовать `details`.

| Метод | Путь | Доступ | Тело / результат |
|---|---|---|---|
| GET | /health | Все | 200 `{ok:true}` либо 503 |
| POST | /auth/register | Все | `{email,name,password}` → 201 `{token,user}` |
| POST | /auth/login | Все | `{email,password}` → `{token,user}` |
| POST | /auth/logout | Пользователь | 204, отзыв токенов аккаунта |
| GET | /me | Пользователь | `{id,email,name,role}` |
| PATCH | /me | Пользователь | `{name}` → обновлённый профиль |
| GET | /status | Пользователь | `{llm,model}`; наличие настроек, не проверка доступности API |
| GET | /chats | Пользователь | Собственные диалоги |
| POST | /chats | Пользователь | 201, новый диалог |
| DELETE | /chats/:id | Владелец | 204 |
| GET | /chats/:id/messages | Владелец | Сообщения в порядке id |
| POST | /chats/:id/messages | Владелец | `{content,asOf,detail,includeDemo}` → 201, ответ |
| GET | /sources | Пользователь | Источники и число документов |
| GET | /documents?demo=true | Пользователь | Документы активных источников; demo по умолчанию false |
| GET | /admin/users | Администратор | До 500 пользователей, без хешей |
| PATCH | /admin/users/:id | Администратор | `{active}`; нельзя изменять доступ администраторов |
| GET | /admin/stats | Администратор | users, chats, documents, requests, avg_ms |
| GET | /admin/history | Администратор | Последние 100 поисковых запросов |
| POST | /admin/sources | Администратор | `{name,url?}` → 201, источник |
| PATCH | /admin/sources/:id | Администратор | `{active}` → источник |
| POST | /admin/documents | Администратор | См. IMPORT.md, добавить source_id → 201 `{id,chunks}` |
| DELETE | /admin/documents/:id | Администратор | 204, удаление текста и фрагментов |

`detail` принимает `short` или `detailed`. `includeDemo` — boolean, по умолчанию false. `asOf` обязательно. В режиме без LLM подробность задаёт количество и длину показываемых фрагментов.

Сообщение ассистента содержит `content`, `mode`, `citations`, `created_at`. Режимы: `llm`, `extractive`, `fallback`, `no_data`. Цитаты — снимки названия, URL, источника, дат, текста и признака учебного примера. `[N]` в ответе соответствует id фрагмента, а не порядковому номеру документа.

Коды: 400 — данные неверны; 401 — сессия отсутствует/истекла/отозвана; 403 — нет роли; 404 — диалог не существует или принадлежит другому пользователю; 409 — конфликт/генерация уже идёт; 413 — слишком большой JSON; 429 — лимит запросов; 500 — внутренняя ошибка.

Регистрация и вход: общий лимит 40 запросов за 15 минут на IP. Генерация: 12 запросов за минуту на IP. Значения предназначены для локального учебного приложения. При развёртывании за reverse proxy настройте доверие к прокси осознанно, чтобы не доверять поддельному X-Forwarded-For.
