# Проверка реализации

## Выполнено

- `npm run build`: успешная TypeScript-компиляция сервера и клиента, успешная production-сборка Vite.
- `npm test`: **10 тестов, 10 успешно, 0 ошибок**.
- Интеграционные тесты исполняют SQL в PGlite с реальной схемой PostgreSQL, а запросы проходят через Express/Supertest. Это не отдельный PostgreSQL-сервис и не тест контейнерной сети.

| Тест | Проверяемое поведение |
|---|---|
| Регистрация и вход | bcrypt, запрет самостоятельного назначения admin, дубликат email, неверный пароль |
| Доступ и профиль | 401 без токена, 403 обычному пользователю на admin, валидация, изменение имени |
| Импорт | Сохранение документа и индекса, отказ при неверных датах/источнике, обязательная ссылка |
| Поиск | Русская морфология, дата действия, окончание периода, учебные данные, отключение источника |
| Диалог | Сохранение пары сообщений, цитаты, запрет чтения/удаления/записи чужого диалога |
| Уточнение и отсутствие данных | Поиск по предыдущему вопросу для уточнения, no_data для посторонней темы, статистика |
| Блокировка | Немедленный отзыв токена; разблокировка требует нового входа |
| Удаление и выход | Каскадное удаление сообщений, отзыв сессии после выхода |
| Фрагментация | Размер, перекрытие и полнота покрытия текста |
| Адаптер LLM | Приём корректного ответа, отклонение неизвестного id, резервный режим при HTTP 503 |

## Не проверено в этой среде

- Docker Compose и отдельный сервер PostgreSQL: Docker/psql недоступны. Конфигурация подготовлена, но контейнерный запуск требует проверки на компьютере пользователя.
- Реальный ответ внешней LLM: пользовательский ключ не предоставлен. Тест адаптера использует подменённый fetch, а не платный запрос к модели.
- Визуальный и сквозной браузерный тест: запуск Chromium заблокирован ограничением среды `socket() failed: Operation not permitted`. Проверку экранов и мобильной адаптивности следует выполнить по DEMO.md. Наличие responsive CSS не равно подтверждённой проверке всех устройств.
- Нагрузочное тестирование, аудит безопасности и юридическая экспертиза документов не проводились.

## Воспроизведение

```bash
npm ci
npm run build
npm test
```

Node.js 24. Тестовая база создаётся в памяти и удаляется после завершения тестов; рабочая DATABASE_URL не используется. Платный ключ LLM для тестов не требуется.

При добавлении реального корпуса дополнительно проверьте набор вопросов с заранее известными ответами: правильность ссылок, полноту условий, даты вступления в силу, конфликтующие редакции и явный отказ при отсутствии нормы. Для таких проверок в поставку не включены выдуманные юридически достоверные результаты.
