# Налоговый навигатор

Учебное веб-приложение для поиска сведений о налоговых изменениях. Команда проекта — Матвей Мухамедзянов и Данила Марченков.

Пользователь задаёт вопрос в чате и выбирает дату, на которую нужно проверить сведения. Приложение ищет подходящие фрагменты в загруженных документах, показывает выдержки и даёт ссылки на публикации. История диалогов сохраняется в PostgreSQL. Администратор добавляет источники и загружает документы через раздел «Управление».

## Демонстрация проекта

[Открыть опубликованное приложение](https://tax-assistant-coursework-coco-jambo.vercel.app/)

Приложение размещено на Vercel, база PostgreSQL работает в Neon. Для демонстрации зарегистрируйте обычную учётную запись, откройте новый диалог и оставьте переключатель «Учебные данные» выключенным. Выберите дату 16.11.2026 и задайте вопрос **«Ставка НДС по дате отгрузки»**. В ответе можно раскрыть выдержку и перейти к публикации ФНС. Также доступны примеры по декларациям УСН и 3-НДФЛ за 2025 год.

Инструкция по размещению проекта приведена в [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md).

## Локальный запуск через Docker Compose

Нужны Docker Engine / Docker Desktop с Compose и доступ в интернет для загрузки образов и npm-пакетов.

1. Распакуйте архив и откройте терминал в папке `tax-assistant`.
2. Скопируйте `.env.example` в `.env` (в Windows файл можно скопировать через проводник).
3. Замените `POSTGRES_PASSWORD`, `JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`.
   - JWT_SECRET: случайная строка не короче 32 символов.
   - ADMIN_PASSWORD: от 12 символов, не более 72 байт UTF-8.
   - Для простого запуска используйте в пароле БД латинские буквы и цифры: пароль вставляется в URL подключения.
4. Выполните:

```bash
docker compose up --build -d
```

5. Откройте http://localhost:3000 и войдите с `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
6. Перейдите в «Управление», создайте источник «Учебные примеры». Загрузите `data/demo-document.json` в этот источник.
7. В помощнике включите «Учебные данные», выберите дату не ранее 01.02.2026 и задайте вопрос: **Срок подачи декларации**.
8. Создайте обычный аккаунт через форму регистрации для проверки пользовательских сценариев.

Остановка: `docker compose down`. Данные сохраняются в именованном томе. `docker compose down -v` удаляет базу без возможности восстановления, если нет резервной копии.
Логи: `docker compose logs -f app`. Проверка готовности: http://localhost:3000/api/health.
Администратор создаётся только при отсутствии указанного email. Изменение ADMIN_PASSWORD после создания аккаунта не меняет пароль в БД. Не регистрируйте заранее обычного пользователя с административным email.

## Дополнительный режим пересказа через LLM

Базовый поиск и показ выдержек работают без языковой модели. Для подключения пересказа в `.env` задайте `LLM_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL`. Нужен совместимый с Chat Completions API сервис, поддерживающий `response_format: {type: "json_object"}`. Укажите реальный идентификатор доступной модели у своего провайдера. Ключ не передаётся браузеру.

```dotenv
LLM_BASE_URL=https://example.com/v1
LLM_API_KEY=ваш_ключ
LLM_MODEL=идентификатор_модели
```

Применение: `docker compose up -d --force-recreate app`.
Проверьте правила и стоимость вашего провайдера. Ему передаются текущий вопрос, до шести последних сообщений и найденные фрагменты. При тайм-ауте, ошибке API или неверных ссылках приложение возвращает выдержки с сообщением о резервном режиме. Проверка ссылок не доказывает фактическую корректность текста LLM.

## Загрузка реальных документов

Создайте источник со ссылкой на официальный сайт. Подготовьте JSON по формату `docs/IMPORT.md`: текст документа, точная ссылка, дата публикации, начало и при необходимости окончание действия. Поле `demo` должно быть `false`. Загружайте текст с первоисточника после проверки дат и применимости. Администратор отвечает за проверку документа.

Приложение **не скачивает сайты автоматически** и не гарантирует полноту законодательной базы. Поиск выполняется по загруженному корпусу. Для обновления редакции загрузите новый документ, удалите устаревший либо предварительно завершите его период через SQL; интерфейс редактирования периода существующего документа в эту версию не входит. История ответов хранит снимки цитат и не переписывается после удаления источника.

## Разработка без Docker

Нужны Node.js 24, npm и работающий PostgreSQL 17. Создайте отдельную БД и пользователя. Из корня проекта:

```bash
npm ci
```

Создайте `server/.env`:

```dotenv
DATABASE_URL=postgres://tax_app:password@localhost:5432/tax_assistant
JWT_SECRET=replace-with-random-secret-at-least-32-characters
ADMIN_EMAIL=admin@example.test
ADMIN_PASSWORD=replace-with-your-admin-password
LLM_API_KEY=
LLM_BASE_URL=https://example.com/v1
LLM_MODEL=
```

В двух терминалах:

```bash
npm run dev:server
npm run dev:client
```

Откройте адрес Vite из терминала (обычно http://localhost:5173). Запросы `/api` проксируются на Express, порт 3000. Создайте базу заранее. Таблицы создаются при старте сервера из `server/src/models/schema.sql`.

```bash
npm run build
npm test
```

После сборки для запуска без Vite: `npm start -w server`. Express отдаёт `client/dist` и REST API на одном порту.

## Ограничения учебной версии

- Источники обновляются вручную; нет автоматического сбора сайтов, PDF/OCR и планировщика.
- Поиск полнотекстовый PostgreSQL с русской морфологией, без векторного хранилища. Полнотекстовый запрос может не находить перефразировки.
- Даты фильтруют опубликованные и действующие документы; будущие изменения до даты вступления не показываются.
- Для коротких уточнений используется предыдущий вопрос, а не отдельная LLM-переформулировка. Без LLM система показывает фрагменты и не ведёт полноценный смысловой диалог.
- JWT хранится в sessionStorage текущей вкладки, срок 8 часов. Выход отзывает все текущие токены этого аккаунта. Нет восстановления пароля и подтверждения email.
- Лимиты и блокировка одновременной генерации находятся в памяти одного процесса. Горизонтальное масштабирование потребует общего хранилища блокировок и rate limit.
- Списки ограничены: 200 диалогов/документов, 500 пользователей, 100 последних запросов. Постраничная навигация не реализована.
- Для публичного развёртывания нужны HTTPS, резервное копирование, политика хранения данных, миграции схемы и дополнительное тестирование нагрузки. Compose по умолчанию публикует приложение только на localhost.
