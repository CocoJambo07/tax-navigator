# Публикация на Vercel для сдачи проекта

React-клиент обращается к Express API. Данные приложения хранятся во внешнем PostgreSQL.

## 1. Исходники

Распакуйте архив. Загрузите содержимое папки `tax-assistant` в свой GitHub-репозиторий. Репозиторий можно оставить закрытым. Не загружайте `.env`, пароли и `node_modules`.

## 2. Проект Vercel

В Vercel выберите Add New → Project и импортируйте репозиторий.

- Root Directory: папка, в которой лежит `vercel.json` (корень, если загрузили содержимое `tax-assistant`).
- Framework Preset: Other.
- Install Command: `npm ci`.
- Build Command: `npm run build:vercel`.
- Output Directory: `client/dist`.
- Node.js: 24.x.

Настройки сборки также заданы в `vercel.json`. Не выбирайте `client` в качестве корня: рядом с ним лежит серверная функция `api/index.ts`.

## 3. PostgreSQL и секреты

Подключите PostgreSQL через Vercel Marketplace (например, Neon) либо используйте существующий PostgreSQL с доступом из Vercel. Выбирайте базу рядом с регионом функций. Укажите следующие значения в Settings → Environment Variables для Production:

| Имя | Значение |
| --- | --- |
| DATABASE_URL | Полная строка подключения из провайдера, с SSL; для Neon используйте pooled connection string |
| JWT_SECRET | Случайная строка длиной от 32 символов |
| ADMIN_EMAIL | Ваш email администратора |
| ADMIN_PASSWORD | Уникальный пароль: минимум 12 символов, максимум 72 байта UTF-8 |

Пример названий переменных — `.env.vercel.example`. Не оставляйте примерные значения. Сгенерировать JWT_SECRET локально можно командой `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`. Не добавляйте секреты в переменные с префиксом `VITE_`.

Таблицы и администратор создаются при первом API-запросе. Запуски нескольких экземпляров сериализуются транзакционной блокировкой PostgreSQL. Повторный запуск не стирает данные и не меняет существующий пароль. Если email уже занят обычным пользователем, инициализация завершится ошибкой: используйте отдельный административный адрес.

## 4. Публичная ссылка

Выполните Production Deploy. После изменения переменных окружения сделайте Redeploy. Проверьте `/api/health`: ожидается `{"ok":true}`.

В Settings → Deployment Protection настройте доступ к production-домену так, чтобы проверяющему не требовался аккаунт Vercel. Откройте production URL в приватном окне браузера: должна появиться форма входа самого проекта. Вход/регистрация внутри приложения остаются обязательными для личных диалогов. Исходники и учётные данные администратора публичными делать не нужно.

## 5. Подготовка к демонстрации

1. Войдите с ADMIN_EMAIL / ADMIN_PASSWORD.
2. В разделе «Управление» создайте источник «Учебные примеры».
3. Загрузите `data/demo-document.json` в этот источник.
4. В помощнике включите «Учебные данные», выберите дату не ранее 01.02.2026 и спросите «Срок подачи декларации».
5. Проверьте цитаты, историю диалогов и сохранение после обновления страницы.
6. В другом браузере зарегистрируйте обычного пользователя; убедитесь, что чужая история и управление ему недоступны.
7. Проверьте открытие и обновление страниц `/sources` и `/profile`.

Документ из комплекта содержит ВЫМЫШЛЕННЫЕ нормы и предназначен только для проверки механики. Для реальных ответов загрузите проверенные документы по `docs/IMPORT.md`.

## LLM — необязательное подключение

Без внешнего AI-ключа работают регистрация, документы, PostgreSQL-поиск, цитаты и история. Ответы выдаются выдержками, полноценной генерации нет.
Для генерации задайте `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` у совместимого провайдера, затем выполните Redeploy. Вызовы API могут тарифицироваться провайдером. Реальная работа внешней модели проверяется отдельно после подключения ключа.

## Что проверено и что ещё предстоит

Локальные сборка и тесты фиксируются в `VALIDATION.md`. Успешная локальная проверка не заменяет deployment: после подключения аккаунтов необходимо проверить маршруты и PostgreSQL на реальном production URL.

Текущие лимиты запросов и блокировки генерации хранятся в памяти каждого экземпляра. Это ограничение учебного проекта: при масштабировании они не являются единым лимитом для всех экземпляров. Не используйте эту версию как нагруженный коммерческий сервис без дополнительной доработки.
